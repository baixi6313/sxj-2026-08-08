# 事现鉴·化债范式 — 待发展城市在三元体系内重定义 & 货币消失→实物/公共工程债务重定义（讨论稿）

> 性质：**讨论稿 / 非 canon**。本稿承接《化债引擎→canon 映射》§4「待继续讨论」与《化债范式合成》§4「未决」，细化两议题的共创论框架。
> 裁定状态：截至本稿，化债引擎三件套 + 范式四件套（五卡/财政直销/消费=纳税+化债/货币消失/交互验证）已升 spec；**本稿两议题仍待白玺专门裁定进 spec**。

## §0 一句话定位
- 财政直销的试点城市，不是"挑一个经济发达省市"，而是把**经济欠发达 / 待发展城市**放进共创论三元体系里**重定义其价值**，再据此注入共济值 A 基值。
- 货币消失后的实物 / 公共工程债务（植树造林、修路等），不退回旧理论的"工分制"，而在共创论下重写为**价值净值 + 动态均衡机制（Gzz）**里的 ρ 缺口，由动态均衡闭合。
- 总纲口号：**打资本 · 分数据 · 化解债务**。
- 化债真正内核（§3.3）：**负贡献核算 ∥ 生成新贡献 并行 → 置换现有债务 → 贡献净值**；货币消失（D机制 c→1）是这一置换完成的**终态结果**，不是手段。

## §2 待发展城市在共创论三元体系内重定义（财政直销落地形态）

### 2.1 旧透镜 vs 共创论透镜
- **旧透镜**：城市价值 = GDP / 财政收入 / 货币财富。结论：商业平台只聚在发达省市 → 财政直销（社保卡 + 数字人民币）"仅限经济发达省市跑通"。
- **共创论透镜**（坐标系优先原则 2026-08-08）：价值 = 三元体系 (自然 / 人文 / 数字) × (上 / 中 / 下) × 组织层级，j = 法域，ρ = 可验证密度，t = 时间。城市不是"穷"，是**其价值没被旧货币度量捕获**。

### 2.2 三元重定义后的待发展城市
- **自然枝 ρ**：生态资产（植树造林存量、土地、水源、碳汇）——可验证密度。
- **人文枝 ρ**：劳动力、养老护理人力、社区资本——可验证密度。
- **数字枝 ρ**：数据资产——可验证密度（关键：数据作为价值被承认，而非资本独占）。
- 财政直销注入的**共济值 A 基值**，按 ρ（可验证密度）定，**不按旧财政收入定**。→ 即便"经济欠发达"，只要三元 ρ 可验证，就能拿到匹配的共济值 A 基值。

### 2.3 为何试点选待发展城市（如彬州市）
- **反证逻辑**：若连待发展城市都能凭三元 ρ 拿到共济值 A 基值、跑通「财政直销 + 五卡 + 数字人民币」，则"仅限经济发达省市"的担忧被破除。
- 这正是口号前半段落地：**分数据**（数字枝数据被承认为价值，成为基值来源之一）＋ **打资本**（打破旧资本 / GDP 对"价值是什么"的定义垄断，改由三元 ρ 定义）。

## §3 货币消失 → 实物 / 公共工程债务重定义：旧理论 vs 共创论

### 3.1 旧理论参照 = 工分制
- 若退回旧框架，"货币消失"会落到**工分制**（劳动工分记账）式代偿：债务以"工分 / 劳动量"核销。这是旧共产理论的惯性类比，**不是共创论路径**。

### 3.2 共创论路径 = 价值净值 + 动态均衡机制（Gzz）
- **货币消失** = D 机制 50% 终态（基值跨全球中位数 50% → 货币消失，贡献值 B 成自由行动层）。
- **Gzz（光锥舟）** = MAIP（测 ρ 的公共验算尺）+ 坐标（x,y,z,t,ρ,j）+ 验证包裹（交互验证，确保 ρ 真实、不可虚记）。
- 实物 / 公共工程债务在三元坐标下**重写为 ρ 缺口**，由动态均衡闭合：

| 旧债务表述 | 共创论重写（落点示例） | 动态均衡闭合 |
|---|---|---|
| 欠 X 元工程款（植树造林） | (x=自然枝, y=中/下档, z=组织层级, j, t)；ρ=生态可验证密度（成活株数 / 碳汇 / 生物多样性增量）；**Δρ=待补齐缺口** | 主动投入(人工造林)→贡献值 B 净值；被动承载(气候/土壤基线)→共济值 A；缺口经动态均衡闭合 |
| 欠 X 元工程款（修路） | (x=人文枝基础设施 / 数字枝连通)；ρ=通达 / 连通可验证密度；**Δρ=待补齐缺口** | 同上：主动→B，被动→A，动态均衡闭合 |

- **关键区别**：债务不再以"元"计，而以**价值净值 + ρ 缺口**计；Gzz 验证包裹确保 ρ 真实，避免虚假记账。这就是口号末段**化解债务**的落地——债务在三元坐标内被重定义为 ρ 缺口，而非货币欠额，经动态均衡（Gzz）闭合。

### 3.3 化债核心闭环：负贡献核算 ∥ 新贡献生成 → 置换现有债务 → 贡献净值

> 白玺 2026-08-10 08:13 裁定要点：「这里面重要的是负贡献核算和生成新贡献并行，最终置换现有债务达到贡献净值。」

这是化债引擎的**真正内核**，也是把"货币消失"从"动作"还原为"结果"的关键：

1. **负贡献核算（珊瑚·追责）**：用归责四要件（主体性＋因果性＋可避免性＋修复性）锁定"谁、因何、可避免、可修复"地制造／放大了债务或损害，记为**负贡献**（珊瑚）。注意：负贡献只计入净值、不抵销个人生存权（共济值 A），不与"被动承担"混淆（被动承担归 A 且不构成负贡献）。
2. **生成新贡献（金·B）**：在同一坐标、同一时段，把植树造林／修路／数据供给等可验证 ρ 记为**新贡献值 B**（金）。这是"主动抉择"的兑现。
3. **并行（∥）**：① 与 ② 不是"先罚后奖"的串行，而是**同时发生**——债务在被记账追责的同时，也被新贡献注入对冲。会计上两条轨道共进：追踪存量旧债的同时，累积负贡献与新贡献。
4. **置换现有债务**：当「新贡献累计 − 负贡献累计 ≥ 待消耗旧债」，旧货币债务即被"贡献净值"**置换**（取代）。公式化即既有模型 ⑤ 的净值式：`N(t) = [η·g·t − L₀ − l·t] − (1−c)·P(t)`，其中 `η·g·t` 类"新贡献生成"，`L₀+l·t` 类"负贡献核算"，`(1−c)·P(t)` 为尚待共济承接的被动残量；当 N(t 转正且残留被吸收，旧债即被净值置换。
5. **达到贡献净值**：终态不再以"欠 X 元"计，而以**每个人的贡献净值 N(t)** 计——可正（B 主导）或归 A（被动承载）。旧债权／债务关系消解，换成"净值账"。货币消失（D机制 c→1）是这一置换完成的**自然结果**，不是手段本身。

→ 把 §3.1／§3.2 收口：**货币消失 ≠ 抹掉债务**；共创论的化债 = 负贡献核算 ∥ 新贡献生成 → 把旧货币债务置换为贡献净值。口号对应：打资本＝负贡献核算（锁定责任方／资本性债务源头），分数据＝新贡献生成通道（数据作可验证 ρ 计入 B），化解债务＝置换 → 净值。

## §4 口号映射：打资本 · 分数据 · 化解债务
- **打资本**＝**负贡献核算**：锁定责任方／资本性债务源头（归责四要件），把旧资本对"价值＋债务"的隐性定义权显影为可问责的负贡献（珊瑚）。
  - ⚠️ **边界**：「打资本 / 推翻资本」作为修辞**仍隔离、未入 spec**（与千问「推翻资本」修辞同处理）。本稿记录其为白玺口号；其**机制内核 = 负贡献核算（三值已 canon）**，修辞本身待专门裁定。
- **分数据**＝**新贡献生成通道**：数字枝数据作为可验证 ρ 被承认、计入贡献值 B（非资本独占）→ 既是财政直销基值来源之一，也是"生成新贡献"的主通道。
- **化解债务**＝**置换现有债务 → 贡献净值**：旧货币债务经 §3.3 双轨并行被净值置换，终态为 N(t) 而非"欠 X 元"（货币消失是 c→1 的伴随结果）。非货币核销、非遗分制。
