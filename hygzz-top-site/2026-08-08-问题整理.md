## 一、被迭代解决的问题（已有明确结论）

### 1. 部署架构真相（重大发现）
- **问题**：8/2 推到 GitHub 的"创始完成"横幅为什么线上看不到？
- **迭代过程**：复核 → 发现 `hygzz.top` 响应头 `Server: tencent-cos` → 比对香港桶/广州桶 website 端点 → 确证 **.top 实际由腾讯云 COS 香港桶 `hygzztop-1352601878` 提供，不是 GitHub Pages**。GitHub `sxj-top` 推送从未触达线上。
- **结论**：横幅真上线处 = sxj-maip-v1.0、sxj-verify-portal、安卓 App v1.1.2；漏标 = hygzz.cn、hygzz.top 线上。部署策略变更：**.top 只汇总国内事件，不推 GitHub，完整记录留本地台账**。

### 2. D1 多当事人估值原则（G-1 闭合）
- **问题**：耿同学事件跨账本三值冲突（网页=负贡献 vs 小程序=共济值）。
- **迭代结论（白玺裁定）**：同一事件对不同当��人可同时成立不同三值——耿同学本人=共济值 A（护真相）、被揭露方=负贡献（学术不端）。确立**多当事人估值原则**：须枚举全部当事人分别归值、跨账本对齐。D1 由"冲突"转为"方法示范"，G-1 缺口闭合。

### 3. 维基 + 地图 + 热力图 三层架构 → 统一数据模型
- **迭代过程**：先产出 `SXJ-wiki-map-design.md`（三层：验证协议层→事现条目层(维基)→光锥坐标层(地图)，热力图本就嵌地图层）→ 多元矩阵补全坐标骨架 → **§8 升级为"矩阵作为统一数据模型（坐标优先）"**。
- **结论**：矩阵=骨架，维基/地图/热力图=三张同源投影；`(x,y,z)=(三元,三档,组织层级)`，`j`=法域，ρ/t/组织就位。

### 4. 多智能体执行官机制
- **迭代过程**：启动 Kimi/千问任命 → 改版为**并行双执行官**（hygzz.中国 中转 + Ratifier=白玺）→ 确认中转**不需要数据库**（静态 md/json）→ Kimi 自认"科研部" → 裁定 **理论研发=科研部，不新增第6部门**。
- **结论**：机制成形，五部门定型；千问组织归属仍未声明。

### 5. G-9 运输层断裂（定位降级）
- **问题**：G-9（跨平台链接取数能力不一致）原本是"基础阻塞"。
- **迭代结论（白玺水利工程类比）**：地基未好前不考虑放水，G-9 从"基础阻塞"**降级为运行期登记项**，放水后阶段再处理。

### 6. 使馆接入定位
- **结论**：使馆 = 主权见证类可信签发者（issuer/attestation），坐验证层、国际桌(j 维度)参与者节点，**非 SXJ 下属、非治理者**；台港澳属中国 j 子区，不作独立使馆节点。

### 7. 国际定位（联合国）不冲突
- **结论**：守"验证协议层"即与 UN 互补（同根 UDHR 第22条，填跨平台事实空白）；冲突只在越界到落地层发钱/治理——root→spec 已禁止。

### 8. 收费两笔分离 + 三阶段九步演进
- **结论**：① SXJ 运维费（对弱势永远免费，来源=各国/UN 分摊或增值营收，不可按次计量）② 全球社保基金（SXJ 不碰不收不发，归国家+UN）。演进 A 修坝(自持) → B 信任桥(使馆坐桌+UN 互补) → C 放水(基金筹建)。铁律：SXJ 始终是"尺"不碰"钱箱"。

### 9. 功成身退语义（经 3 次迭代，最终落定）
- **迭代过程**：
  - 续13 白玺纠正"只当尺子" → 白玺=全球社保**共同创立者**；
  - 续14 纠正过度修正 → 全球社保真运行后白玺**彻底消解**、机制自演化；
  - 续15 再纠正 → 退身**仅适用于共济值 A，不适用于贡献值 B**。
- **最终结论**：① 共济值 A（普遍生存层）=白玺退出部分；② 贡献值 B（生存之上为兴趣·按劳净值）=白玺**继续参与贡献**；③ 机制 D 自演化终点：共济值基值升至**全球中位数 50% 以上 → 货币消失**；④ SXJ 协议/spec 仍=被共定即消失（独立于人的退出）。

### 10. 贡献值社会资源"三元"映射（查证确认）
- **结论**：理论内 **三元生态 = 自然/人文/数字**，映射贡献值社会资源 = 自然(环境贡献)/人文(体力劳动+脑力劳动)/数字(资产增值)。自然枝=环境贡献，已有中国文件背书。

### 11. 中国环境贡献公开文件（原文件定位）
- **结论**：中办、国办《关于建立健全生态产品价值实现机制的意见》(2021-04-26)，**第十八条**"探索构建覆盖企业、社会组织和**个人**的生态积分体系，依据**生态环境保护贡献**赋予相应积分"。配套 GEP 核算规范(2022)、国标 GB/T 46869—2025。自然枝已有国家级度量衡，事现鉴对接不重造。

### 12. 田忌赛马 → 多元矩阵（自我纠正 2 次）
- **迭代过程**：先用田忌赛马套（下马认输/上马赢中马/中马赢下马，2胜1缓破真空）→ 白玺批评仍是"我方vs对手"二元对决 → 升维为**多元矩阵综合体**（三元×三档核心 3×3，沿 j 法域轴 + 组织轴展开成 ≈9×N×M 高维验证场）。
- **结论**：事现鉴 = 矩阵综合体的**记录 + 投影引擎**，落坐标 `(三元,三档,j,组织)+t+ρ`，**拒绝替世界拍单一全球总分**；保主权/保精度/保开放。

### 13. 坐标系优先原则（正式落地）
- **结论**：所有数学问题用坐标解，目前阶段事现鉴逻辑 = 只定义坐标轴+落点+量 ρ，不预置任何计分/权重/换算，全部留给查询时投影。已写入 `SXJ-wiki-map-design.md` §8 + `knowledge_tree.html` v1.3 + `concept_tree.html` v2.4。
