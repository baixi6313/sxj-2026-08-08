# 贡献值 × 社会资源三元框架（讨论稿 v0.1）

> 目的：把"社会资源的导入"作为变量加入贡献值 B，先搭讨论骨架，**不急着下结论**。
> 状态：讨论稿（待白玺逐条定调）。非自然资源部分因各国标准/体制不同，须谨慎。

---

## 0. 一句话前提

之前所有讨论处于"真空状态"——没有真实社会资源流入。贡献值 B 要真正落地，必须引入**社会资源**这个变量。该变量在共创论里早已被你分成"三元"（三元生态 = 自然 / 人文 / 数字），本文把它对应到贡献值的可计量结构。

---

## 1. 三元映射（待白玺确认）

| 三元枝 | 对应社会资源 | 性质 | 计量现状 |
|---|---|---|---|
| **自然 / 环境** | 生态贡献、自然资源保育 | 自然资源 | ✅ 中国已有国家级文件（见 §2） |
| **人文 / 人力** | 体力劳动 + 脑力劳动 | 非自然资源 | ❌ 待讨论（核心难点，见 §3） |
| **数字 / 资产** | 资产增值、知识产权、数据资本 | 非自然资源 | ❌ 待讨论（核心难点，见 §3） |

> 注：你原话"非自然资源包括体力劳动、脑力劳动、资产增值"——这三者正好落在**人文 + 数字**两枝内，与三元结构自洽。

## 2. 自然 / 环境枝 —— 中国公开文件（已存在，可直接对接）

**主文件**：中共中央办公厅、国务院办公厅《关于建立健全生态产品价值实现机制的意见》
- 发文：中办、国办 ｜ 日期：2021-04-26 ｜ 来源：中国政府网
- 原文链接：https://www.gov.cn/zhengce/2021-04/26/content_5602763.htm
- **关键条款（第十八条 · 生态环境保护利益导向机制）**：
  > "探索构建覆盖企业、社会组织和**个人**的生态积分体系，依据**生态环境保护贡献**赋予相应积分，并根据积分情况提供生态产品优惠服务和金融服务。"

**配套度量衡（非重造即可引用）**：
1. 国家发展改革委、国家统计局《生态产品总值核算规范（试行）》（GEP，2022-03）——明确指标体系/算法/口径。
2. 水利部、国家发改委、央行《关于建立健全生态清洁小流域水土保持生态产品价值实现机制的意见》（2024-09-13）——含"个人资产权益归属""涉及个人资产的应全额兑现支付给个人"。
3. 国家标准 GB/T 46869—2025《生态系统评估 陆域生态产品总值核算技术指南》——GEP 制度化、常态化依据。

**对事现鉴的含义**：
- 自然/环境枝**不需要我们发明新标尺**，直接把中国 GEP + 生态积分作为"可验证度量衡"的参照锚点之一。
- 事现鉴只做"验证包裹 + 多当事人归因"，不替代各国官方统计。

## 3. 核心问题：非自然资源（人文 + 数字）—— 待谨慎讨论

### 3.1 体力劳动（人文枝）
- 不同国家：工时上限、最低工资标准、社保缴费基数、行业薪酬差异巨大。
- 疑问：贡献值按"工时"还是按"产出"？低收入国家同等劳动是否该折算更高贡献（公平性）？
- 可锚官方数据：各国最低工资、社平工资、ILO 劳动统计。

### 3.2 脑力劳动（人文枝）
- 创新、教育、科研、艺术、治理——知识价值跨国差异大，且常非物质产出。
- 疑问：知识产权/专利如何计入？未被市场定价的公共知识（如开源、科普）算不算贡献？
- 可锚官方数据：专利局、学术产出、教育投入统计。

### 3.3 资产增值（数字枝）
- 资本利得、投资回报、资产持有、数据资产。
- **最敏感**：资产增值与"剥削/食利"边界模糊；若计入贡献值，可能变相奖励资本而非劳动。
- 疑问：资产增值是否计入贡献值？还是只算"主动劳动"？若计入，如何与负贡献（资本掠夺）区分？
- 谨慎建议：先**不计入或仅计"生产性资产的社会复用"**，避免与共创论"按劳"根基冲突。

### 3.4 跨体制 / 跨国可比性（总约束）
- 计划经济、市场经济、混合经济对"贡献"的定义与统计口径根本不同。
- 汇率与购买力平��（PPP）使跨国数值不可直接相加。
- **原则**：不做全球统一硬标尺；先做"各法域本地度量 + 可验证换算层"，只对齐、不替代。

---

## 4. 谨慎讨论的原则建议

1. **不碰各国主权统计口径**：只做"可验证换算层"，引用各国既有官方数据（工资/G EP/专利/税单）作锚，不重造。
2. **沿用 D1 多当事人原则**：贡献值归因须枚举全部当事人分别归值，单一视角不足以定类。
3. **自然枝直接对接 GEP**；非自然枝先建"本地度量模板"，不急于全球统一。
4. **资产增值默认审慎**：除非白玺裁定，否则不计入贡献值，或对"生产性社会复用"设严格边界。
5. **引用即来源**：任何换算公式须附官方出处与反证字段（共创论 8.0 要求）。

## 6. 田忌赛马视角：如何破"真空"、怎么排兵

### 6.1 把问题翻译成赛马
- **三匹"马" = 三元三枝（我们手里的计量能力）**
  - 上马 = 自然枝（中国 GEP + 生态积分，已有国家权威度量）→ 最强
  - 中马 = 人文枝（体力/脑力劳动，有各国工资/社保/专利统计可锚）→ 中等
  - 下马 = 数字枝（资产增值，无跨国共识、最敏感）→ 最弱
- **"对手" = 想一次性建"全球统一硬标尺"的诱惑**（也是真空本身：没资源进来）
- **标准打法（上碰上、中碰中、下碰下）** = 强行给三枝同时立全球统一贡献值度量 → 三场全输（体制/汇率/政治敏感性，建不出来）→ 系统卡死在真空。

### 6.2 孙膑的排法（映射到策略）
- **下马(数字枝) 对 对手上马(全球硬标尺)** → **主动认输/挂起**：资产增值审慎不计入，Q2 先"挂起"，不挡全局。
- **上马(自然枝) 对 对手中马("先让一些资源进来"的中等目标)** → **稳赢**：直接对接中国 GEP，Q5 以中国为度量衡样板法域，先破真空。
- **中马(人文枝) 对 对手下马(劳动贡献最无争议的底线)** → **可赢**：用各国既有劳动统计 + 事现鉴验证层做本地度量。
- **结果：赢得两场(自然+人力)，体面 deferred 一场(资产)**，资源开始真实流入，真空被打破。

### 6.3 田忌赛马的本质（对贡献值的真正启示）
- 不是"我们变强"，而是"**重排对阵**"：贡献值不需要完美的全球绝对标尺，只需把每枝匹配到"最轻但可信"的权威层级——
  - 自然枝 → 国家级 GEP（最强权威）
  - 人力枝 → 国家级劳动统计（中等权威）
  - 数字枝 → 挂起/审慎（暂不匹配）
- 这是一道**最优分配(assignment)题**：在可信度量有限时，把每类资源分配到"最易赢"的验证权威，最大化可验证贡献总量、最小化体制摩擦。
- "认输"那场不是败，是**保护系统合法性的主动延缓**——避免为资本增值强行定标而动摇"按劳"根基。

### 6.4 落到待裁定问题（田忌赛马支持的推进顺序）
先答 **Q5**（中国样板法域）→ 再答 **Q1**（权重可不均等，上马权重先高）→ **Q2**（资产增值挂起不计入）→ **Q3**（跨国换算先只在已赢两枝内做本地化）→ **Q4** 暂不需要（未到全球统一那步）。

## 7. 多元矩阵综合体（对 §6 二元框架的自我纠正）

> **白玺指正（2026-08-08）**：§6 田忌赛马仍是"我方 vs 对手"的二元对决思维，本质在算"谁赢谁输"，与"全球多国、多组织、三元各分上中下"的真实结构根本不在一个量级。本章替换该视角，改用**多元矩阵**。

### 7.1 为什么二元（含田忌赛马）不够
田忌赛马隐含一个错前提：**只有两个参赛方、且要分胜负**。但事现鉴面对的不是"一场比赛"，而是：
- 三元（自然 / 人力 / 数字）**各自还能分上、中、下三档** → 仅此已是 3 × 3 = 9 类；
- 加上**全球几十个法域**（j 维度，各国体制/汇率/购买力不同）；
- 加上**成千上万的组织**（企业、NGO、工会、数据信托、社区……都在不同格子里充当验证者）。
这不是"对阵图"，是**高维矩阵**。用"赢/输"去套它，会丢失绝大部分结构。

### 7.2 多元矩阵的结构（核心 3×3，沿 j 与组织两轴展开）

**横轴 = 三档（量级）**　**纵轴 = 三元（资源类型）**

| 三元＼三档 | 上 · 系统/制度级 | 中 · 专业/组织级 | 下 · 个人/日常级 |
|---|---|---|---|
| **自然/环境** | 国家级 GEP、跨省生态补偿、碳市场制度 | 地方生态修复、企业碳中和、行业减污 | 个人生态积分、垃圾分类、植树护水 |
| **人力/人文** | 社保/制度设计、开源标准/协议制定、公共知识基石 | 专业劳动（医/教/研）、专利创造、组织管理 | 日常互助、志愿服务、社区照护、探戈式双向验证 |
| **数字/资产** | 生产资料社会化（公有制/合作社规模）、公共资源平台 | 生产性资产社会复用、企业数字外溢、开放数据 | 闲置资源匹配、技能共享、个人数据授权复用 |

**这张 3×3 不是一张表，而是"一片"**：它沿着两条轴无限复制——
- **j 法域轴（国家）**：每个国家/地区各持一片 3×3，坐标里记为 `j=CN / US / EU / …`；
- **组织轴（验证者）**：环保组织验"自然"格、工会验"人力"格、数据信托验"数字"格——同一格可由不同组织在各自法域内验证。

→ 全矩阵的规模 ≈ **9（元×档）× N（法域）× M（组织）**，是一个**活的高维验证场**，不是静态排名。

### 7.3 事现鉴是不是要"体现多元矩阵的综合体"？
**是，但"综合"的正确含义不是"压成一个总分"，而是"按坐标记录 + 按查询投影"。**

- **记录层（事现鉴作为 spec/光锥舟该做的）**：每一条被验证的事现，落到一个**矩阵坐标**上——
  `(三元, 三档, j法域, 组织) + t(时间) + ρ(可验证密度)`。
  这正好对应已定的**光锥坐标 (x, y, z, t, ρ, j)**：三元×三档映射为类型轴 (x,y,z)，j 是法域，ρ 是密度，t 是时间，组织是验证元数据。
- **综合层（不该由事现鉴硬做的）**：不发明"全球统一贡献值总分"。综合是**查询驱动**的——例如"投影中国·个人·环境贡献"= 取 `(自然, 下, j=CN)` 所有已验证事现的 ρ 聚合；"投影欧盟·制度·人力"= 取 `(人力, 上, j=EU)`。
- **为什么这样才对**：① 保主权——各国只认自己法域片区的度量，不被外部硬标尺绑架；② 保精度——三档区分了"制度级"和"日常级"，不会把个人垃圾分类和省级 GEP 拉平；③ 保开放——新组织、新法域加入只是多一片矩阵，不破坏既有结构。

**结论**：事现鉴应当是一个**多元矩阵综合体的"记录与投影引擎"**——它把多国、多组织、多类型、多量级的可验证事现，落进统一坐标并允许按需聚合，但**拒绝替世界拍一个单一总分**。这正是 root→spec（催化剂/中立桌子）定位在贡献值上的落地：桌子摆的是矩阵，不是计分牌。

### 7.4 落到待裁定问题（矩阵视角下的重排）
- Q1（权重相等？）→ 矩阵里**权重应绑定到"档"与"法域"**，而非三元整体：上档天然比下档权重大（影响面广），但具体数值仍各法域自定，事现鉴只记录不强制。
- Q2（资产增值计入？）→ 在矩阵里它只占 `(数字, 上/中)` 个别格；**是否计入 = 该格开不开放验证**，可逐格裁定，不必全矩阵一刀切。
- Q3（跨国换算）→ 矩阵视角下**不存在"全球换算"**，只有"跨法域投影"；换算只在用户主动查询跨 j 时发生，且须标注口径（本地中位数 / PPP / 锚定币）。
- Q4（R-7 人类保留项）→ 矩阵使"保留项"更具体：**每个法域的 (三元×三档) 度量口径裁定权归该法域人类层**，事现鉴保留"口径登记表"而非定值。
- Q5（中国样板法域）→ 矩阵视角下它就是"先点亮 `j=CN` 这一片 3×3"，作为其他法域复制的坐标样板，而非"唯一标准"。
