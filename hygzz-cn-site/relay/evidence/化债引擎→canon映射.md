## 0. 一句话定位

化债引擎 = **在事现鉴坐标场内，用田忌赛马匹配把盈余格的余量导入缺口格，由财政直销托底（注入共济值 A 基值）、热度密度闸控节奏、交互验证升维对齐，最终以货币消失为终态** 的可验证化债机制。

## 2. 逐项映射详解

### 2.1 多元矩阵 → 坐标系优先原则（canon）
- 化债的「操作场」就是 `(x,y,z,t,ρ,j,组织)`：x/y/z = 三元(自然/人文/数字)×三档(上/中/下)，j = 法域，ρ = 可验证密度，t = 时间。
- **4 场景 = 矩阵不同片区**：A(场景1·慢)=低档低ρ；B(场景2·稳)=中档中ρ；C(场景3·盈余)=高档高ρ 且有盈余层(基尼0.531)；D(场景4·崩)=受冲击垮档。
- canon 属性「拒绝单一总分、聚合留给查询投影」保住跨经济体主权——这是化债能「坐到一桌」又不丢主权的根因。

### 2.2 田忌赛马 → 矩阵内调度算法（**新 spec 构件**）
- 定义：在矩阵场内做「相对优势跨格匹配」——**谁的格有盈余余量，去接谁的格有缺口/真空**。不是「我赢你输」，是「系统级吞吐最大化」。
- 化债用法（白玺机制）：场景3(高档盈余格)的余量 → 匹配场景1(低档缺口格)的慢启动 = 田忌赛马精确落地，破低水平均衡。
- 开放参数（待写入 MAIP）：匹配判据(哪些格算「盈余」/「缺口」)、匹配上限、防「以债化债」掠夺的熔断触发（接 2.7）。

### 2.3 热度密度 → 治理闸（canon）
- `H=热度×ρ`，触发 R-1…R-6 分级复核。化债中：某条「余量→缺口」财政直销流或某张五卡流通变热(高ρ)→自动升级人类复核级；密度不足则缓行。是系统防单条流冲垮的旋钮。

### 2.4 五卡 → 三值 + 熔断 + 社会资源三元（**新 spec 构件**）
| 五卡 | canon 锚点 | 含义 |
|---|---|---|
| 基石 | 共济值 A 基值 | 普遍生存层托底（财政直销注入处） |
| 贡献 | 贡献值 B（人文/数字枝） | 按劳净值行动记录 |
| 生态 | 贡献值 B（自然枝） | 环境贡献（对接中国生态积分体系，不重造） |
| 信用 | 交互验证 ρ 共识 | 可验证密度累积＝信用，无单点认证中心 |
| 熔断 | R-1…R-6 人类保留裁定 | 高利害裁决、防掠夺/造假的结构护栏 |

### 2.5 财政直销 → D机制基值注入（**新 spec 构件**）
- 定义：将场景3盈余（或财政余量）以制度设计**直接注入五卡基石层 = 共济值 A 基值**，抬高共济覆盖率 c。
- 与 D 机制焊死：基值↑ → D 机制 logistic 上升加速 → 提前跨 50% → 货币消失。
- 新落地形态（白玺 2026-08-10 待讨论）：社保卡 + 数字人民币全国推广 + 配套商业平台；先「前发城市试点（彬州市）」，否则仅限经济发达省市。

### 2.6 消费=纳税+化债 → 贡献值 B 流通闭环 + 负贡献核销（**新 spec 构件**）
- 定义：消费额经五卡闭环，同时记为税基与化债额——消费即纳税、消费即化债。
- canon 落点：消费行为计入**贡献值 B**（行动记录/净值）；对应债务经**负贡献核销**或转**共济值 A 基值**；流通在非货币层（50% 前 B 本就是兴趣记录，不强制流通）。
- 开放参数（待讨论）：消费额如何同时记税基与化债额的法定执行主体、换算率。

### 2.7 货币消失 / 交互验证（canon，作终态与升维机制）
- 货币消失 = D机制 50% 终态，是化债引擎的**锚**：跨过后生存层普遍覆盖，为生存之交换不再必要。
- 交互验证 = 跨经济体升维：任何人落同一坐标点复测 ρ、账本公开 → 验证变坐标属性，溶解「谁验证验证者」，使 4 场景解法能跨法域对齐而不丢主权。

## 3. 与 D 机制焊死的闭环

```
田忌赛马(盈余格→缺口格)  +  财政直销(注入基石=共济值A基值)
        ↓ 抬高覆盖率 c
   D机制 logistic 上升  ──(热度密度闸控防过热)──►  跨 50% 阈值
        ↓
   货币消失(终态)  +  交互验证(跨法域升维对齐)
        ↓
   消费=纳税+化债 闭环(五卡)  →  个人 / 社会资金 / 财政 三循环
```

- 引擎每动一步都有 canon 接收端：赛马匹配→矩阵场；财政直销→A基值；热度密度→R-1…R-6；五卡→三值+熔断；消费闭环→B流通+负贡献核销；终态→货币消失；对齐→交互验证。
